## Summary
Create a GitHub Actions workflow that runs lint and tests on pull requests and pushes, and publishes results.

## Scope
- `.github/workflows/ci.yml` triggered on `pull_request` and push to the main branch.
- Steps: checkout, set up Python 3.12, install pinned dependencies (with caching), Ruff, pytest with JUnit XML.
- Upload the JUnit XML as a workflow artifact (always, even on failure) and show a summary in the run.
- Pipeline fails if lint or any test fails.
- No AWS credentials are required to run this workflow.

## Acceptance criteria
- A PR with passing tests shows a green run and a downloadable JUnit artifact.
- A PR with a deliberately failing test shows a red run and the artifact still uploads.
- A PR with a lint violation fails the lint step.
- Workflow uses least-privilege `permissions`.

## Independent test approach
- Use a throwaway branch with a seeded failing test (see DT-015) and a seeded lint error; verify the outcomes. The workflow can be validated with a trivial test suite from DT-001.

## Definition of done
- Green and red run links captured as evidence.
