# DT-012: Container image

| Field | Value |
|---|---|
| Size | S |
| Type | Feature (packaging) |
| Requirements | NFR-05, Acceptance criterion 10 |
| Depends on | DT-001 (a runnable app); DT-011 for the CI build step |
| Test cases | Container build and run checks |

## Summary
Package the API as a Docker image that runs identically locally and in AWS.

## Scope
- `Dockerfile` with a slim Python base image, pinned dependencies, non-root user, and the port set via an environment variable with a default.
- No credentials, account IDs, or environment-specific values baked in.
- `.dockerignore` excludes tests, `.git`, `.env*`, and caches.
- CI job builds the image (no push required in this story).

## Acceptance criteria
- `docker build` succeeds from a clean checkout.
- `docker run -p 8000:8000 <image>` then `GET /health` returns 200 and one valid `/simulate` request returns 200.
- Container runs as a non-root user.
- Image contains no `.env` files or secrets.

## Independent test approach
- Build and run the container locally; run the smoke checks (DT-014) against `http://localhost:8000`.

## Definition of done
- Build step is green in CI; run instructions are in the README.
